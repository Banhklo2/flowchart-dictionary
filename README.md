# 📘 FlowChart Dictionary

**FlowChart로 메뉴 기반 전자사전 로직을 설계하고 Java로 구현한 연습**

---

## ✅ 시나리오: 전자사전 프로그램

- 메뉴를 출력한다.
  - 1. 단어 등록
  - 2. 단어 조회
  - 0. 종료
- 사용자는 메뉴 번호를 입력한다.
- 선택한 메뉴에 따라 기능을 수행한다.
  - 1번 : 단어와 뜻을 등록한다.
  - 2번 : 단어를 입력하면 뜻을 출력한다.
  - 0번 : 프로그램을 종료한다.
- 그 외의 번호가 입력되면  
  → `"잘못된 메뉴입니다"`를 출력하고 다시 메뉴로 돌아간다.

## 📌 입력 / 출력 정리

### 입력(Input)
- 메뉴 번호 `menu`
- 단어 `word`
- 뜻 `mean`

### 출력(Output)
- 단어 등록 완료 메시지
- 단어 조회 결과(뜻 출력)
- 오류 메시지 (`"잘못된 메뉴입니다"`)

### 상태(State)
- 단어 사전 `dictionary`
  - 단어(`word`)와 뜻(`mean`)을 저장하는 구조

---

## 🔎 조건 정리

### 종료 조건
- `menu == 0`

### 분기 조건
- 메뉴 번호가 `1 / 2 / 0` 중 무엇인가

### 예외 / 에러 조건
- 메뉴 번호가 정상 범위가 아닌 경우  
  → `"잘못된 메뉴입니다"` 출력 후 다시 메뉴로

---

## 🔁 로직 흐름 설계

1. 시작 시
   - 메뉴를 출력한다.

2. 반복
   1) 메뉴 번호 `menu`를 입력받는다.  
   2) 입력값을 확인한다.  
      - `menu == 1`  
        → 단어(`word`)와 뜻(`mean`)을 입력받아 사전에 등록  
      - `menu == 2`  
        → 단어를 입력받아 뜻을 출력  
      - `menu == 0`  
        → 프로그램 종료  
      - 그 외  
        → `"잘못된 메뉴입니다"` 출력  
   3) 다시 메뉴를 출력한다.

3. 종료 시
- 프로그램 종료
